# ks1686/scoop-bucket

Self-hosted [Scoop](https://scoop.sh) bucket for [genv](https://github.com/ks1686/genv).
Not submitted to Scoop extras or the scoop.sh directory.

## Install

```powershell
scoop bucket add ks1686 https://github.com/ks1686/scoop-bucket
scoop install genv
```

Manifests live at the repository root and are published from the genv release workflow.
